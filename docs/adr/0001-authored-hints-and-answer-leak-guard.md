# คำใบ้ต้นฉบับเป็นข้อมูลหลัก LLM ทำได้แค่ปรับถ้อยคำ

ทุก Item มี Authored Hint ครบ 3 ระดับที่ครูเขียนไว้ LLM (Claude หรือ Gemini) ทำได้แค่ปรับถ้อยคำให้เข้ากับนักเรียน และทุกข้อความจาก LLM ต้องผ่าน Answer-Leak Guard ก่อนถึงนักเรียน ถ้าพบคำตอบสุดท้าย หรือ Provider ใช้ไม่ได้ ระบบจะใช้ Authored Hint แทน การตัดสินถูกผิดและการเลือกเส้นทางทั้งหมดเป็นกฎที่ตรวจสอบได้ LLM ไม่มีส่วนตัดสิน เราเลือกแบบนี้เพราะ prompt อย่างเดียวรับประกันไม่ได้ว่าจะไม่หลุดเฉลย (LLM เป็นเพียง Next Token Prediction) ระบบต้องสาธิตได้แม้ไม่มีอินเทอร์เน็ต และทุกการตัดสินใจต้องอธิบายได้

## Considered Options

- ให้ LLM แต่งคำใบ้เองทั้งหมดและเชื่อ prompt 4 กรอบ: อ้างว่า "ไม่หลุดเฉลย 100%" ไม่ได้ และระบบใช้งานไม่ได้เมื่อ API ล่ม
- ให้ LLM ตรวจคำตอบที่เป็นข้อความอิสระ: กฎ 3 ด่านจะอธิบายไม่ได้ จึงรับเฉพาะ Answer Format ที่ตรวจด้วยกฎได้ คือ ปรนัย ตัวเลข และข้อความสั้น

## Consequences

- ครูต้องเขียนคำใบ้ครบ 3 ระดับให้ทุก Item และ Readiness Check จะไม่ให้เปิดใช้ Question Set ที่คำใบ้ไม่ครบ
