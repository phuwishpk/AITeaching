# Gem: AI สร้างบทเรียนทั้งชุด แต่กฎยังเป็นผู้ตัดสินถูกผิด

ครูสร้างบทเรียนเป็น Gem แบบ Gemini Gem คือกรอกชื่อ คำอธิบาย คำสั่ง เครื่องมือเริ่มต้น และ Knowledge File แล้ว LLM สร้าง Knowledge Map, Item, Authored Hint 3 ระดับ, Bug Library, Isomorphic Item และ Remedial Item ให้ทั้งหมด แต่ทุก Item ต้องมาพร้อม Answer Key แบบมีโครงสร้าง (Answer Format, คำตอบที่ถูก, คำตอบที่ยอมรับ) และ engine ยังตรวจคำตอบด้วยกฎ ใช้ 3 ด่าน บันไดคำใบ้ และ Remedial Loop เหมือนเดิม Answer Key ทุกข้อผ่าน Answer Key Check ก่อนถึงนักเรียน ถ้าไม่ผ่านจะเป็น Flagged Item ที่ซ่อนไว้จนครูยืนยัน

เราเลือกแบบนี้เพราะต้องการให้ครูสร้างบทเรียนได้ง่ายแบบ Gemini โดยไม่เสียสิ่งที่ ADR-0001 ปกป้องไว้ คือการตัดสินถูกผิดที่อธิบายได้ และ LLM ไม่มีอำนาจตัดสินแทนกฎ

## Considered Options

- Gem เป็นแค่บุคลิกของติวเตอร์ ครูยังเขียนโจทย์เอง: ปลอดภัยที่สุด แต่ไม่ได้ประสบการณ์แบบ Gemini Gem ที่ผู้ใช้ต้องการ
- Gem เป็นแชตล้วนที่ LLM ถามและตัดสินเอง: ผังตรรกะ Decision Trace และหัวข้อ 3, 5, 6 ของการนำเสนอจะไม่มีอะไรให้แสดง
- LLM ตัดสินคำตอบเชิงอธิบาย: คะแนนผันผวนตาม LLM และ Rapid Guess กับ Mastery อธิบายไม่ได้

## Consequences

- ระบบทำงานออนไลน์เท่านั้นสำหรับการสร้าง Gem และงานสดของ AI (ยกเลิกข้อกำหนดการสาธิตแบบออฟไลน์เมื่อ 25 ต.ค. 2569)
- เฉลยจาก LLM อาจผิด จึงต้องมี Answer Key Check สองชั้น: LLM แก้โจทย์ซ้ำโดยไม่เห็นเฉลย และ sympy คำนวณเฉลยจริงเมื่อเป็นสมการหรือเลขคณิต
- ครูยังแก้ Knowledge Map และคำสั่งของ Gem ได้ แต่แก้ Constraints & Fallback ไม่ได้ ข้อห้ามหลักล็อกไว้ในโค้ด
