# Adaptive Tutor

ระบบติวเตอร์อัจฉริยะ (Intelligent Tutoring System) สำหรับวิชาคณิตศาสตร์ ม.2 เรื่องการแก้สมการเชิงเส้นตัวแปรเดียว ระบบรอให้นักเรียนคิดเองก่อน แล้วจึงช่วยด้วยคำใบ้ทีละขั้นโดยไม่เฉลย ครูดูแลรายคนได้แบบสด และหน้าผู้ดูแลระบบแสดงตรรกะทุกขั้นตามโครงการนำเสนอ 7 หัวข้อ

- **หลังบ้าน (EDM):** FastAPI + SQLite มีกฎ 3 ด่านแบบ If-Else ซ้อนกัน, Fuzzy Logic, K-Means ที่เขียนเอง และ AI Tutor ที่ใช้ RAG (BM25 + PyThaiNLP) กับ Claude หรือ Gemini
- **หน้าบ้าน (LA):** React + Vite มี 3 บทบาท คือนักเรียน ครู และผู้ดูแลระบบ รองรับโหมดมืดและจอมือถือ

## เริ่มใช้งาน

ต้องมี Python 3.11 ขึ้นไป (ทดสอบกับ 3.14) และ Node.js 22 ขึ้นไป

```bash
./run.sh
```

สคริปต์ติดตั้งแพ็กเกจครั้งแรก build หน้าเว็บเมื่อโค้ดเปลี่ยน แล้วเปิดระบบที่ <http://localhost:8000>

บน Windows ให้รันทีละขั้นแทน:

```powershell
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
cd ..\frontend
npm ci
npm run build
cd ..\backend
.venv\Scripts\uvicorn app.main:app --port 8000
```

### เข้าระบบสำหรับสาธิต

| บทบาท | วิธีเข้า | เห็นอะไร |
|---|---|---|
| นักเรียน | รหัส `S-01` ถึง `S-06` (ชื่อสมมติ) | โจทย์ คำใบ้ แชต และแถบความก้าวหน้า ไม่เห็นตัวเลขความเสี่ยง |
| ครู | กดเข้าได้ทันที | สร้าง Gem แบบ Gemini, รับแจ้งเตือนและเข้าช่วยนักเรียน, ชื่อจริง Risk Score และ Manual Override |
| ผู้ดูแลระบบ | กดเข้าได้ทันที | Flow ที่ครูออกแบบใน Gem แต่ละตัว ผังตรรกะสด 7 แท็บ ไทม์ไลน์ครูกับนักเรียน และใส่ API key เห็นนักเรียนเป็นรหัสเท่านั้น แก้ Gem ไม่ได้ |

หน้าครูและหน้าผู้ดูแลระบบไม่มี PIN ใครเปิด URL ได้ก็เข้าได้ ค่าเริ่มต้นจึงเปิดให้เข้าจากเครื่องนี้เท่านั้น

## ใส่ Gemini API key

Gem ต้องใช้ AI ทั้งตอนสร้างคลังโจทย์ ตอนครูผู้ช่วยตอบแชต และตอนสร้างโจทย์สด จึงต้องใส่ key และต่ออินเทอร์เน็ต:

1. เข้า ผู้ดูแลระบบ → ตั้งค่า
2. วาง key ในช่อง Gemini แล้วกดบันทึก (Claude เป็นตัวสำรองพับไว้ด้านล่าง ใส่ด้วยก็ได้)
3. กด "ทดสอบการเชื่อมต่อ" แล้วเลือกโมเดลจากรายการ ถ้ารุ่นที่เลือกมีผู้ใช้มาก ระบบสลับไปรุ่นสำรองของ Gemini เอง

key เก็บในไฟล์ `runtime/secrets.json` บนเครื่องนี้ หน้าเว็บแสดงแค่ 4 ตัวท้าย หรือตั้งตัวแปร `ANTHROPIC_API_KEY` / `GEMINI_API_KEY` ก่อนเปิดเซิร์ฟเวอร์ก็ได้ (ค่าจากตัวแปรมีสิทธิ์เหนือไฟล์)

## สร้าง Gem (ครู)

1. ครู → Gem ของฉัน → Gem ใหม่
2. ตั้งชื่อ คำอธิบาย และคำสั่ง (ปุ่มไม้กายสิทธิ์ให้ AI ช่วยเกลา) เลือกเครื่องมือเริ่มต้น การแจ้งเตือนครู และแนบไฟล์ความรู้
3. กดบันทึก AI สร้างแผนผังความรู้ โจทย์ คำใบ้ 3 ระดับ และ Bug Library ประมาณ 1 นาที เฉลยที่ตรวจไม่ผ่านจะติดธงและซ่อนจากนักเรียนจนครูยืนยัน
4. ลองเรียนเป็นนักเรียนได้ที่แท็บ "ลองเรียน" นักเรียนเห็น Gem เป็นการ์ดทันทีที่สร้างเสร็จ
5. ตรวจโจทย์ที่แท็บคลังโจทย์: อนุมัติ แก้ เพิ่มเอง ลบ หรือกด "AI สร้างเพิ่ม" (ข้อใหม่รอครูอนุมัติก่อนถึงนักเรียน) โจทย์ที่ AI สร้างสดระหว่างเรียนขึ้นในรายการ "สร้างสดรอตรวจ"

การสาธิตหัวข้อ 5–6 และนักเรียนจำลองใช้ Gem ที่เลือกไว้ในหน้า ผู้ดูแลระบบ → Gem ที่ครูออกแบบ → "ใช้ Gem นี้สาธิตหัวข้อ 2–6"

ดูการออกแบบและเหตุผลทั้งหมดใน [docs/decisions.md](docs/decisions.md) หัวข้อ Gem และ [ADR-0003](docs/adr/0003-gems-ai-builds-lessons-rules-still-grade.md)

## ลำดับการสาธิต (5 นาที)

1. เปิดหน้าผู้ดูแลระบบ กด **Presentation View** ใช้ลูกศรซ้ายขวาเปลี่ยนหัวข้อ
2. แท็บ 1–2: ปัญหาของ Static CAI และสถาปัตยกรรม 4 แบบจำลอง พร้อมข้อมูลจริงของนักเรียนที่เลือก
3. แท็บ 3: ผังตรรกะสด ชิปบนกล่องคือนักเรียนที่อยู่ตรงนั้น กดกล่องเพื่อดูหลักการ
4. แท็บ 5: กด "หน้านักเรียน" ของสถานการณ์ที่ต้องการให้เปิดอีกแท็บ แล้วกด "เริ่มสาธิต" ผังจะขยับตามทุกก้าว
5. แท็บ 6: Stress Test 11 กรณีรันกับ engine ตัวจริง
6. หน้าครู: เปิดนักเรียนที่ติด แล้วกด Manual Override ให้เห็นว่าครูตัดสินใจขั้นสุดท้าย

เปิด Demo Mode (แท็บ 5 หรือหน้าตั้งค่า) เพื่อย่อเวลารอ เช่น Deliberate Delay 15 วินาทีเหลือ 3 วินาที

## โครงสร้าง

```
backend/app/
  engine/      กฎ 3 ด่าน บันไดคำใบ้ Remedial Loop และผังตรรกะ (flow.py)
  ml/          Fuzzy Logic และ K-Means เขียนเองตามบทเรียน
  tutor/       prompt 4 กรอบ, RAG, Answer-Leak Guard, ตรวจข้อความทุกข์ใจ, ลบข้อมูลส่วนตัว
  content/     ตัวตรวจความพร้อม และชุดโจทย์ตัวอย่างที่ใช้ในเทสต์เท่านั้น (ไม่ได้ติดตั้งลงระบบ)
  gems/        Gem: สร้างคลังด้วย AI ตรวจเฉลย แจ้งเตือนครู และให้ครูตรวจโจทย์ทีละข้อ
  api/         endpoint ของแต่ละบทบาท
  principles.py  ข้อความการ์ดหลักการและเนื้อหา 7 หัวข้อ (แก้ข้อความได้ที่นี่)
frontend/src/
  pages/student · pages/teacher · pages/admin
  components/  ผังตรรกะ แผนผังความรู้ กราฟ และ UI พื้นฐาน
docs/          decisions.md, flow.md และ ADR
CONTEXT.md     อภิธานศัพท์ของโปรเจกต์
```

## พัฒนาต่อ

```bash
# เทสต์หลังบ้าน
cd backend && .venv/bin/python -m pytest

# หลังบ้านโหมดแก้โค้ด (รีโหลดเอง)
cd backend && .venv/bin/uvicorn app.main:app --reload --port 8000

# หน้าบ้านโหมดแก้โค้ด ที่ http://localhost:5173 (ส่งต่อ /api และ /ws ไปที่พอร์ต 8000)
cd frontend && npm run dev
```

## ข้อมูลและความเป็นส่วนตัว

repo นี้เป็นสาธารณะ ห้าม commit API key ข้อมูลนักเรียน หรือเอกสารบทเรียนของอาจารย์ ข้อมูลที่ระบบสร้างตอนทำงานอยู่ใน `runtime/` (ฐานข้อมูล ร่องรอยการเรียน และ key) ซึ่ง git ไม่เก็บ ส่วนเอกสารบทเรียนวางไว้ใน `reference/` ได้โดยไม่ขึ้น repo

ถ้าจะให้นักเรียนในห้องเข้าจากเครื่องอื่น ให้เปิดด้วย `HOST=0.0.0.0 ./run.sh` ในเครือข่ายที่ไว้ใจได้เท่านั้น และระวังว่าทุกเครื่องในเครือข่ายนั้นจะเปิดหน้าครูได้ด้วย ซึ่งเห็นชื่อจริงและ Risk Score ของนักเรียน
